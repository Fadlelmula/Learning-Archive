## 👋 Who's Writing This

I'm getting back into coding, and I'll be honest: **I remember almost nothing**. The skills are rusty, so I'm rebuilding them from the basics, in public, one concept at a time.

The goal? Become the next Tony Stark: someone who can build anything and make it look exactly the way I imagine it. Tony didn't start with the Mark 85. He started in a cave with a box of scraps. 🔧

So this folder is **Mark I**: ugly, clunky, but it works, and every iteration gets better.

> 🧠 **Honesty policy:** I'm going to get things wrong here. When I do, it goes in [`notes/things-i-broke.md`](../notes/things-i-broke.md), and when something finally clicks, it goes in [`notes/things-i-finally-understood.md`](../notes/things-i-finally-understood.md).
