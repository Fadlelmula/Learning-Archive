# 📚 XYZ Bookstore

*A little page where two books bloom on a shelf, and a checkout flow whispers "not yet" back at you.* 🕸️🥀

## What's here

A single static page (`index.html`) with:

- A header and a bit of shop-keeper charm
- Two book cards — Sally's interdimensional sci-fi and Dave's flour-dusted cooking saga
- "Buy Now" buttons on each card
- A "View Cart" and "Checkout" button at the bottom

## Current state 🕯️

Right now this is a **skeleton, not a shop**. Like a spider lily — striking bloom, no leaves in sight — the markup is here but nothing underneath it moves yet:

- No CSS. It's rendering in plain default browser styling.
- No JavaScript. "Buy Now," "View Cart," and "Checkout" are buttons in name only — nothing fires when clicked.
- No cart state, no data, no logic connecting the books to anything.

## Running it

Just open `index.html` in a browser. No build step, no server, no dependencies — the simplest possible thing that could exist.
